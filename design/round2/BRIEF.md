# Myself 视觉第二轮 · 共享简报

上一轮三套全站方案被判定「都不好看」。原因诊断（请务必规避）：
1. **平均用力**：每屏都塞满卡片 + 小标签 + 小图标 + 等宽编号，信息噪音大，没有主角。
2. **长页平铺**：把十几屏竖着堆成一张长图，失去产品感。这一轮每个产出必须是**可点、可切换的真实界面**（单页应用式交互），不是海报。
3. **风格贴皮**：套一个风格名（太空图录 / 原研哉），细节却是通用组件。质感来自细节：光影层次、阴影的颜色、字重梯度、对齐、行高、动效曲线、空状态、hover/active/focus 每一种状态。
4. **缺少「一个值得截图的瞬间」**：每个产出至少要有一处让人想截图发朋友圈的细节。

## 品牌与现状

- 项目：Myself，开源个人博客引擎，作者 BeaconCat。内容：文章（长文，封面 1-3 张）+ 随想（短内容流，≤9 图）+ 关于页（模块化自我介绍）。
- logo：`design/round2/logo.png`（深海军蓝底上一扇打开的门：左白页 + 右钴蓝页 + 地面透出的光）。母题：**门、光、书页**。
- 现有站点截图：`design/round2/reference/`（d-* 桌面，m-* 移动 390 宽）。现有气质：深海军蓝底 `#0B1220` 一带、钴蓝主色、玻璃胶囊导航、3D 封面卡。**这是起点，可以大胆超越，但要让老用户认得出来。**
- 品牌信号三色（不可改，只做点睛）：`#ff0032` 红、`#ffb300` 黄、`#0078ff` 蓝。
- 主题：`mode`(light/dark) × `palette`（春 `#00c853` / 夏 `#ff0032` / 秋 `#ffb300` / 冬 `#0078ff`，每组 primary + primaryDeep，整套变量运行时派生）。每个产出都要有深浅切换 + 色盘切换，并且切换本身要有动效。
- 字体：思源黑体（UI/正文）+ 思源宋体（标题/文章）。演示可用 Google Fonts `Noto Sans SC` / `Noto Serif SC`；数字/代码可配一款等宽（JetBrains Mono / Geist Mono）或西文衬线。最终落地会换成离线 woff2。
- 硬禁区：emoji；紫色渐变；「此处待完善 / Coming soon / 敬请期待」类文案；SVG 手画人物；圆角卡片 + 左侧彩色竖条。未实现功能要画成完整可信的 UI（示例数据）。
- 动效 token：`--dur-fast .2s / --dur .35s / --dur-slow .6s`，`--ease-out cubic-bezier(.2,.8,.3,1)`，`--ease-spring cubic-bezier(.2,.8,.3,1.2)`；必须尊重 `prefers-reduced-motion`。
- 图标：演示用内联 SVG 线性图标（1.5px stroke，统一 24 网格），落地时换 iconfont。

## 技术要求

- 纯 HTML + CSS + 原生 JS 单文件，不用任何外部 JS 库（字体 link 除外）。
- 所有颜色 / 间距 / 圆角 / 阴影 / 动效走 CSS 变量，文件顶部注释写清 token 与设计决策，方便翻译成 Vue + SCSS。
- 自检流程：写完用 Playwright 截图（scratchpad 里已装好：`<scratchpad>/node_modules/playwright`，用 `require('<该路径>')`），Read 截图，**以挑剔设计总监的眼光至少迭代两轮**：对齐、留白、层级、对比度、深浅两种模式都要看。截图存到你自己的产出目录的 `shots/`。
- 不要 git commit。
