MYSELF DESIGN SYSTEM · ROUND 3 · 强调系统

光留给门缝，控件只做信号

渐变填充、同色外发光、文字投影三件套从全站撤下。选中态改为一块中性抬升面；主色退回为信号——链接、焦点、进度、当前位置点，以及每屏至多一个主按钮。发光只保留给品牌母题「门缝光」本身。

R1选中 = 中性抬升

选中项是一块比容器略亮的中性面（深 = 文字色 10%，浅 = 白 + 1px 阴影），文字切满对比；块在项之间 morph。

R2主色 = 一个信号

每组控件主色至多出现一次：3px 圆点、2px 线、或选中图标着色。链接 / 焦点环 / 进度 / 当前位置也属信号。

R3主按钮 = 实底

无渐变、无彩色外发光、无文字投影；体积靠 1px 顶部内高光 + 0.5px 描边 + 1–2px 中性紧阴影。hover 调明度，按下 .97。

R4对比自动计算

亮主色（春绿、秋黄）自动用深字；其余白字，底色向黑推到对比 ≥ 4.5。链接色同理推到对背景 ≥ 4.5。

R5发光只属于品牌

blur / glow 仅用于封面光影构成与 Hero 门缝光外溢；控件、卡片一律中性阴影，阴影色不带主色。

R6标签去色块

列表中写作「# 名称」纯文字；需要可点区域时用极轻描边胶囊。行距与间距放宽，标签不再抢标题。
