用 Markdown 写作

文章与随想共用一条 Markdown 管线：可移植、可版本化、对 AI 友好。

为什么是 Markdown

正文以纯文本存进 SQLite，导出即 .md 文件；渲染统一走 client/src/utils/markdown.ts，代码高亮与 TOC 锚点在同一处生成。

写作的成本应该只剩下想清楚要说什么。
