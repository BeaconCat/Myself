主题系统指南

两层主题架构：深浅模式与色盘正交组合；后台可自定义最多十组主题色并拖拽排序。

Myself 的主题不是一张张独立的皮肤，而是两个正交的维度：模式（light / dark）决定明暗关系，色盘（palette）决定主色。任意组合都成立，因为整套变量在运行时从一对主色派生。

两层架构

模式回答「底是亮的还是暗的」，色盘回答「这个站今天是什么颜色」。它们被写在根元素的两个属性上：

html<html data-mode="dark" data-palette="winter">

三种品牌信号色（红 / 黄 / 蓝）贯穿所有主题、不随色盘变化，用于状态与标记；季节主色只影响强调、焦点与「光」。

内置四季预设

预设primaryprimaryDeep气质
春 · spring#00c853#00893a新绿
夏 · summer#ff0032#b8001f炽红
秋 · autumn#ffb300#b87d00暖阳
冬 · winter#0078ff#0052c2霜蓝

运行时派生

每组预设只保存两个值。derive.ts 在客户端把它们展开为整套 light + dark 变量并注入 :root，不维护任何独立的色盘文件：

tsexport function derive(primary: string, deep: string) {
  const soft = mix(primary, 'transparent', 0.16)
  const line = mix(primary, 'transparent', 0.45)
  // 只派生「强调」相关的变量，中性灰阶由 mode 决定
  return { '--primary': primary, '--primary-deep': deep,
           '--primary-soft': soft, '--primary-line': line }
}

色相是最贵的资源。把它从界面里抽走，留给内容和一束光。

—— 本站设计原则

后台自定义

在「设置 · 主题预设」里最多可以维护十组主色，支持拖拽排序；第一组即默认主题。切换时前台会以点击位置为圆心做一次圆形蒙版扩散。

  • 在后台新增一组主色并命名
  • 拖拽到第一位设为默认
  • 为浅色模式单独校对对比度（自动派生已覆盖大部分场景）

动效与降级

所有过渡都读取统一的 motion tokens（--dur / --ease-out / --ease-spring），并尊重 prefers-reduced-motion：开启后蒙版扩散退化为直接切换。
