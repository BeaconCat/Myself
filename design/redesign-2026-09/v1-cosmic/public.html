欢迎使用 Myself

一个开源的个人博客引擎：Vue 3 + Go + SQLite，内容皆 Markdown，主题随四季流转。

2026-07-01 6 分钟阅读 指南BeaconCat

Myself 是一个为「一个人」设计的博客引擎。它不追求多租户、插件市场或复杂的权限体系，只做一件事：让你在自己的域名下，用 Markdown 安静地写作，并把这些内容以最讲究的方式呈现出来。

§ 01为什么又造一个博客引擎

市面上的博客系统大多在两个极端之间摇摆：要么是静态生成器，写一篇文章需要打开编辑器、提交、等待构建；要么是笨重的 CMS，功能繁多但与「写作」这件事渐行渐远。Myself 想站在中间——有后台，但后台只服务于一个人；有 API，但 API 只为了让你的 AI 助手替你发文。

记录本身，就是意义。写下来，才算真正发生过。— 站点格言

§ 02架构一览

整个项目是一个 monorepo：前端 Vue 3 + Vite，后端 Go 标准库 net/http + SQLite，最终编译为一个单独的二进制文件，前端产物通过 go:embed 内嵌，部署时只需要复制一个文件。

前端

主题系统分两层：mode（深 / 浅）与 palette（四季色盘）正交组合，所有色彩变量在运行时从一对主色派生并注入 :root。动效遵循一组统一的 motion tokens，并尊重 prefers-reduced-motion。

后端

后端没有引入任何 cgo 依赖，图片处理与备份都由纯 Go 完成。下面是一个最小的启动片段：

Gopackage main

import (
    "log"
    "net/http"
    "myself/internal/httpapi"
)

func main() {
    // 单二进制：SPA + API 同端口
    mux := httpapi.NewMux(httpapi.Options{DataDir: "./data"})
    log.Fatal(http.ListenAndServe(":8080", mux))
}

§ 03两种内容形态

形态长度封面 / 配图典型用途
文章 Post长文，带目录最多 3 张封面，手风琴展示教程、复盘、长篇随笔
随想 Note一段话到几段话最多 9 张，九宫格日常记录、想法碎片、图片流
关于 About模块化区块头像用站点 logo作者介绍、技能、里程碑

§ 04接下来做什么

装好之后，建议按下面的顺序走一遍——每一步都只需要几分钟：

  • 在后台换上你的名字与主题色
  • 发布第一篇文章
  • 创建 APIKey，把发文托管给 AI
  • 开启自动备份，并把备份文件同步到别处

如果你喜欢这个项目，欢迎到 GitHub 拿源码自建一份——它就是为此而生的。
