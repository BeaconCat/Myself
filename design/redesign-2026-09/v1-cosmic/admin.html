把发文托管给 AI：API 中心

创建 APIKey，让外部 AI 通过 X-Api-Key 认证的 REST 接口替你发布文章与随想。

§ 01为什么要有 API 中心

写作最难的是「开始」。把草稿的生成交给 AI，把审核与发布留给自己——这是 Myself 的 API 中心想解决的事。

内容统一走 Markdown，人和 AI 写出来的东西长得一样。

§ 02三步接入

  • 在后台「API 中心」创建一把 Key（只显示一次）
  • 请求头带上 X-Api-Key: mk_live_…
  • POST /api/v1/posts 提交 Markdown 正文与元信息

§ 03安全边界

Key 可随时吊销；默认只能创建草稿，是否直接发布由每把 Key 的权限决定。
