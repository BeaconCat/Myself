# Myself 全站视觉翻新 · 设计 Spec（三版方案共同输入）

> 本文件是三个并行设计版本的唯一共同输入。每版独立工作、只看本 spec，互不参考。

## 1. 项目是什么

**Myself** 是一个开源的个人博客引擎（Vue 3 前端 + Go 后端 + SQLite），作者是个人开发者 BeaconCat。它同时是「作者自己的博客」和「可分发给别人自建的产品」。内容形态两种：

- **文章（Post）**：长文，Markdown，有封面（最多 3 张，封面手风琴）、标签、摘要、置顶、草稿/已发布。
- **随想（Note / Thoughts）**：短内容流，类 X/Twitter 的卡片，支持心情标签、最多 9 张配图（九宫格）、置顶、按日期筛选、媒体墙视图。

另有「关于」页（模块化区块：统计、技能、里程碑、GitHub 状态、社交、技术栈、语录、FAQ、画廊、Now、联系方式等 16 种）、RSS、标签、搜索。

后台是管理员单人使用的控制台，外部 AI 助手可通过 APIKey 投稿。

## 2. 目标受众与使用场景

- **访客**：读长文、刷随想、看作者是谁。桌面为主，手机次之。阅读距离 60cm 笔记本。
- **作者本人**：每天打开后台写随想、偶尔写长文、管理素材与设置。要求「顺手、快、不打扰」。
- **潜在自建用户**：看到这个博客觉得「好看、想要」→ 去 GitHub 拿源码。所以前台本身是产品展示。

## 3. 情感基调与气质关键词

用户原话：**简洁、美观、大气、高级感**。

补充理解：不是冷冰冰的 SaaS 极简，而是「有作者体温的高级」——像一本装帧讲究的个人文集，或一间灯光克制的私人书房。品牌 logo 是「打开的门/书页透出光」（白页 + 钴蓝页 + 地面光晕，深海军蓝底），母题是 **光、门、书页、灯塔**（作者名 BeaconCat，早期 logo 是灯塔 + 信号波）。

气质词：沉静 / 克制 / 精致 / 有光感 / 编辑感 / 不喧哗。

## 4. 品牌约束（必须遵守）

- **品牌常量三色（贯穿所有主题，不可改）**：`--accent-red: #ff0032`、`--accent-yellow: #ffb300`、`--accent-blue: #0078ff`。三色是「信号色」，用于强调点、状态、标记，**不要**大面积铺。
- **底色**：logo 深海军蓝近黑（约 `#070B14` ~ `#0B1220`）。浅色模式底可自定，但要和 logo 气质一致。
- **主题系统**：两层 `mode`（light/dark）× `palette`（四季预设：春新绿 `#00c853`、夏炽红 `#ff0032`、秋暖阳 `#ffb300`、冬霜蓝 `#0078ff`，每组仅 primary + primaryDeep，整套变量运行时派生）。设计稿默认展示 **深色 + 冬霜蓝** 与 **浅色 + 夏炽红** 两种即可，其它靠变量派生。
- **字体**：思源黑体（UI/正文）+ 思源宋体（标题/文章）。演示文件可用 Google Fonts `Noto Sans SC` / `Noto Serif SC` 加载，或本地 `client/node_modules/@fontsource/noto-sans-sc` / `noto-serif-sc`。英文/数字可搭配一款有性格的西文（衬线或等宽），但不要 Inter/Roboto 当 display。
- **logo 文件**：`E:\Users\BeaconCat\Downloads\Myself\design\logo.png`（开门/书页），请 base64 内嵌或相对路径引用。
- **禁区**：严禁 emoji；严禁紫色渐变；严禁圆角卡片 + 左彩色 border accent 的组合；严禁 SVG 手画人物；严禁「此处待完善」「Coming soon」式占位文案——**未实现功能必须画成完整可信的 UI**（例如评论区就画出真实的评论列表与输入框，只是数据是示例）。
- **动效**：全站要有节制而流畅的动效：页面进场、滚动 reveal、悬停微动、3D 卡片倾斜、毛玻璃层。统一 motion tokens：`--dur-fast: .2s / --dur: .35s / --dur-slow: .6s`，`--ease-out: cubic-bezier(.2,.8,.3,1)`，`--ease-spring: cubic-bezier(.2,.8,.3,1.2)`。尊重 `prefers-reduced-motion`。

## 5. 信息架构（业务闭环，两端都要画）

### 5.1 用户前端（public.html）

按顺序在同一个 HTML 内做成可滚动的多个「屏」，每屏用 `<section data-screen="...">` 包裹并加一行小标题说明这是哪一页：

1. **首页 Home**
   - 顶部导航：PC 毛玻璃胶囊导航（首页 / 文章 / 随想 / 关于 + 搜索 + 主题切换 + RSS）；移动端悬浮顶栏 + 汉堡。
   - **Hero 轮播**：左侧大标题 + 摘要 + 标签（文字随机模糊切入/飞出），右侧封面卡 3D 飞入飞出（一组 1-3 张封面轮转，每 10 秒换一篇文章）。要体现「光」的母题。
   - 最新文章（3-4 篇）、随想流预览（2-3 条）、关于我小卡（头像 / 一句话 / GitHub 统计条）。
2. **文章列表 Articles**：标签筛选条、搜索、列表项（封面缩略 + 标题 + 摘要 + 日期 + 标签），无限滚动到底标注语。
3. **文章详情 Article**：封面手风琴带（宽于正文栏）、标题区（日期 / 标签 / 阅读时长）、正文 Markdown 排版（h2/h3/引用/代码块带语言角标/表格/任务列表）、右侧固定 TOC、文末上一篇/下一篇、相关文章、**评论区（预留：画出完整评论列表 + 回复 + 输入框）**。
4. **随想 Thoughts**：顶部 tab（信息流 / 媒体墙）、搜索、日期范围快捷选择；卡片（头像 / 名字 / 时间 / 心情标签 / Markdown 短文 / 九宫格图）；媒体墙（图片瀑布）。
5. **关于 About**：身份卡（头像 / 名字 / tagline / 建站运行天数 / 格言），下面模块化区块至少画 5 个：统计、技能分组、里程碑时间线、GitHub 热力图 + 最近提交、社交链接。
6. **搜索 Search**：全局搜索浮层（命令面板式，文章 / 随想 / 标签混合结果）。
7. **404**：品牌化空页。

### 5.2 管理员后台（admin.html）

同样多屏平铺。后台是**桌面优先**的控制台，可以有侧栏，也可以不要侧栏（由设计决定），但必须承载以下模块：

1. **登录**：品牌化登录页（logo、用户名、密码、记住我）。
2. **概览 Dashboard**：内容统计（文章数 / 随想数 / 素材数 / 备份数）、最近 7 天发布趋势（小图表）、最近动态（谁通过 APIKey 投了什么）、系统状态（数据库大小 / 上次备份 / GitHub 同步时间）、快捷动作（写随想 / 写文章 / 上传素材）。
3. **文章管理**：列表（状态筛选 草稿/已发布/置顶、搜索、排序）+ **编辑器页**：左 Markdown 源 / 右实时预览（或富文本 + 元信息侧栏：slug / 封面 / 标签 / 摘要 / 状态 / 置顶 / **定时发布（预留）**），底部发布条。
4. **随想管理**：顶部 composer（输入框 + 心情 + 九图上传 + 发布），下方卡片列表可编辑/置顶/删除。
5. **素材库 Media**：网格（缩略图 / 大小 / 已裁切标记）、拖拽上传区、裁切弹层、**图片质量优化任务**（扫描列表 + 压缩进度条 + 结果）。
6. **关于管理**：模块列表可拖拽排序 + 行内编辑 + 「添加模块」选择器。
7. **外观与站点设置**：分区导航（站点 / 加载 / 主题预设 10 组可拖拽 / 首页 Hero 规则 / 时区 / GitHub / 备份 / 账号密码）。
8. **API 中心**：APIKey 列表（名称 / 前缀 / 最后使用 / 吊销）、创建弹层（Key 只显示一次）、接口目录文档、在线调试台、**调用日志（预留）**。
9. **数据中心**：备份列表（立即备份 / 下载 / 删除 / 自动备份间隔）、**导入导出（预留）**。
10. **评论与用户（P4 预留）**：评论审核列表、用户列表——画成完整 UI，示例数据。

## 7. 图片策略

封面 / 配图是内容必需，但本项目没有固定的真实照片库。演示文件里封面用**本地渐变占位图**（项目自带能力：`/api/v1/img/<from>/<to>/<label>` 生成带文字的渐变 SVG）——设计稿内请用同样思路：CSS 渐变 + 一行标签文字的占位卡，颜色取自品牌三色与四季色。头像用 logo。**不要**去外网拉 stock 图。

## 8. 输出格式与尺寸（三版统一）

- 两个文件：`public.html`、`admin.html`，纯 HTML + CSS + 少量原生 JS（用于 tab 切换 / 主题切换 / hero 轮播演示），**不用任何框架与外部 JS 库**。
- 视口基准 **1440 × 900**，每个「屏」高度可超过 900 自然滚动。截图用 Playwright `--viewport-size=1440,900 --full-page`。
- 文件内顶部用 HTML 注释写清：本版设计逻辑、参照、假设、哪些是预留 UI。
- 每个 `<section data-screen>` 顶部左上角放一枚极小的灰色 label（如「01 · 首页」）方便审阅，不参与设计本身。
- 提供一个 `THEME.md`（≤ 60 行）：配色 token、字体配对、圆角/阴影/间距尺度、动效清单——后续落地到 Vue 时直接照抄。

## 9. 评审标准（用户会按这个选）

1. 第一眼是否「高级」——不靠堆效果，靠留白、排印、对比与克制的光。
2. 品牌识别度——能不能一眼认出这是 Myself（门/光/三信号色）。
3. 业务闭环完整——前台 7 屏 + 后台 10 屏都在，且未实现功能画得像真的。
4. 可落地——token 化、组件化、能翻译成 Vue + SCSS。
