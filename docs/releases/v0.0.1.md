# Myself Alpha

**v0.0.1 · 2026-10-02 · 首个公开预发布版本**

Myself 是一个可自托管的个人博客引擎，把文章、随想、关于页与日常管理放在同一个站点中。生产环境运行一个程序即可提供页面、API、素材和 RSS；前端、字体与 SQLite 随程序内置，无需 Node.js 或外置数据库，也可选择 MySQL。

## 本次发布

- **文章与随想**：Markdown、富文本/源码切换、草稿、定时发布、标签、多封面与素材嵌入。定时发布支持修改、取消和服务恢复后的到期补发。
- **个人表达**：26 种关于页模块，统一身份管理，深浅模式、四季色盘、自定义主色和页面动效。
- **独立移动界面**：阅读、写作、定时发布、关于页管理和素材操作；随想列表显示相对时间，详情提供完整时间和浏览量。
- **内容与互动管理**：素材文件夹、图片处理、作者与读者权限、评论审核、留言墙、回应和 API 中心。
- **Agent 接入**：可复制或下载的提示词涵盖权限、Markdown、定时发布、时区、完整字段更新、排期取消和错误处理，并附文章与随想的请求示例。
- **数据与维护**：SQLite / MySQL、整站备份恢复、Markdown 迁移、后台检查更新，以及程序替换失败时的回退。

## 下载与启动

附件中，每个平台提供原始二进制与部署包。首次安装建议选择 `.zip`（Windows）或 `.tar.gz`（Linux / macOS），并使用 `SHA256SUMS` 校验。

| 系统 | 架构 |
| --- | --- |
| Windows | amd64、386、arm64 |
| macOS | amd64、arm64 |
| Linux | amd64、386、arm、arm64、riscv64 |

解压后把 `config.example.json` 复制为 `config.json`，在该目录运行：

```sh
# Linux / macOS
./myself --config ./config.json
```

```powershell
# Windows PowerShell
.\myself.exe --config .\config.json
```

打开 `http://localhost:3100`，从终端日志取得初始化码并创建站长账号。默认数据目录为 `runtime/`，没有默认管理员密码。

`release-manifest.json` 为后台更新提供版本、平台与校验信息；需要完整部署说明时请查看包内 README 或[仓库部署文档](https://github.com/BeaconCat/Myself/blob/v0.0.1/deploy/README.md)。

## Alpha 说明

这是预发布版本，适合试用与反馈。界面目前为简体中文，部署按域名根路径设计；Windows/macOS 程序尚未进行商业代码签名。功能和数据结构仍会演进，升级前请创建并下载完整备份。

发行流程验证前端构建、SQLite/MySQL 回归、十个目标平台的安装包启动与图片处理，以及真实程序更新和失败回退。
